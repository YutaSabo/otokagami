# Otokagami 製品目標

> 文書状態: 現役
> 上位方針: [マスター設計書](../../マスター設計書.md)

## 製品の一文定義

> Otokagamiは、英語が伝わりにくくなる音を改善したい学習者のために、毎日1つの焦点音を管理課題で見つけ、短いコツと再録音でその場の変化を示し、別の単語・文と後日の無補助判定で定着まで確認する発音改善アプリである。

## 解決する問題

- 総合点だけでは、次にどの音をどう直すか分からない。
- コツの直後に点数が上がっても、翌日や別の語で再現できるか分からない。
- 詳細情報や練習入口が多いと、短時間で再挑戦しにくい。
- 発音学習を休むと、続きではなく大量の未消化課題やストリーク喪失が前面に出やすい。

Otokagamiは、改善対象を毎日1音へ絞り、「発見」「即時変化」「後日再現」「別文脈への転移」を別々の証拠として見せる。

| 項目 | 決定 |

| 製品全体 | 国籍・母語を問わず英語の明瞭さを改善したい学習者 |
| 最初の市場 | 日本 |

## 中心価値

### 毎日得る価値

ユーザーは各日に、少なくとも次の一つを理解できる。

- 次に直す焦点音が見つかった。
- コツを試した直後に変化した。
- 前回の変化を別日にも維持できた。
- 別の単語・文へ転移できた。
- 定着確認が一段進んだ。

点数が上がらない日でも、維持できたこと、技術的に判定できなかったこと、次に試すことを区別する。

### 差別化

音素判定、再録音、口・舌の説明だけでは独自性にならない。Otokagamiは次を一つの学習記録として結ぶ。

```text
無補助の発見 → 1つのコツ → guided retry → 別日の無補助確認 → 別課題への転移
```

同日の改善を「定着」と呼ばないことが中心原則である。

### 課金後も続ける理由

販売するのは機能数ではなく、次を含む個別改善計画である。

- 次に扱う焦点音
- 期限の来た復習
- 単語から実用文への難度上昇
- 維持・転移・定着の証拠
- 次の1〜2週間の見通し

## 成功状態

### ユーザー成功

- Day 1に焦点音と次の1行動が分かる。
- 同日にbefore／afterの変化を確認できる。
- 別日の無補助attemptで維持を確認できる。
- 別語・別文で転移を確認できる。
- 7 active learning days後も、14日以降の計画が自然に続く。

### 製品成功の仮説

最重要指標は「14日以内に、1つ以上の焦点音が定着へ到達した利用者の割合」とする。併せて次を測る。

- Day 1有効セッション完了率
- 焦点音発見率、guided retry率、即時変化率
- 翌日以降の無補助確認率、転移率
- Day 7レポート到達率、購入率
- 有料利用者のDay 14・Day 30継続率
- 復習実行率、技術失敗率、主要結果P95、Azure原価

各go/no-go値はTBDであり、収益化を保証しない。

## 設計原則

1. 次に直す1音と1行動を最初に示す。
2. 通常5課題で3〜5分を目指し、良好日は短縮する。
3. コーチは1動作、再録音は原則1課題に絞る。
4. guided retryとdurable進捗を分離する。
5. 休んでも状態を罰せず、期限超過復習を1件ずつ戻す。
6. Azure結果を人間評価と断定しない。
7. 機能数より、速度・安定性・分かりやすさ・再挑戦しやすさを優先する。

## 対象外のユーザー・用途

- 自由会話、AIロールプレイを主目的とする人
- 任意文章を発音判定したい人
- 英語試験スコア予測、同時通訳、会議監視を求める人
- 医療・言語聴覚療法を必要とする人
- ネイティブらしさの順位付けを求める人
- 子ども向け専用教育

## 収益化仮説

ユーザーは7 active learning daysで「自分の焦点音」「その場の変化」「後日または別文脈での再現」を確認し、始まった14日以降の計画を継続するために月額または年額購読を選ぶ、という仮説を検証する。
